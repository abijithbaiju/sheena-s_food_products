SHEENAS FOOD PRODUCT — WEBSITE PROJECT
======================================

FILES
- index.html     Homepage
- products.html  Product catalogue, filters, jar sizes, cart and combo offer
- about.html     Brand story
- contact.html   Contact form that prepares an enquiry in WhatsApp
- style.css      Custom styling
- app.js         Product, cart, pricing and WhatsApp checkout logic
- Image files    Product and brand imagery used by the pages

HOW TO RUN
1. Extract the ZIP archive completely.
2. Keep all HTML, CSS, JavaScript and image files in the same folder.
3. Open index.html in a modern browser.
4. Internet access is needed for Tailwind CDN, Google Fonts, Font Awesome and WhatsApp.

ORDERING
- The cart runs in the browser and saves its contents in local browser storage.
- Checkout opens WhatsApp with a prepared order summary. The customer must send the message to submit the order.
- This is a front-end project. It does not process payments, reserve inventory, or store confirmed orders on a server.
